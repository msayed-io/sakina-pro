# أرضية توافق التحديث الصامت (OTA)

`min-native-version.txt` يحوي **أقل إصدار APK** يستطيع تشغيل حزمة الويب المنشورة.

- ارفع الرقم **فقط** عند إضافة/حذف بلوجن أصلي (Capacitor plugin) أو تغيير
  `applicationId` أو أي سطح أصلي جديد تعتمد عليه طبقة الويب.
- لا ترفعه عند تعديلات الويب/React العادية، وإلا تجمّد التحديث الصامت
  لكل من على إصدار APK أقدم.

القيمة الحالية `2.3.45` = أول إصدار APK يحتوي `@capgo/capacitor-updater`.
أي جهاز على APK أقدم لا يستقبل تحديثات ويب (حمايته من تعطّل غير متوقع).
