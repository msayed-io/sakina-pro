# منظومة الحديث في سكينة

تعتمد منظومة الحديث في تطبيق سكينة على تسع قواعد SQLite مستقلة، تُنزّل عند طلب المستخدم من إصدارات مستودع البيانات الرسمي:

- المستودع: https://github.com/msayed-io/sakina-hadith-data
- الإصدار الحالي: `v1.0.0`
- مصدر الاستخراج الموثق: مكتبة الشاملة، وفق توثيق مستودع البيانات.

## الكتب

تتضمن النسخة الحالية: صحيح البخاري، صحيح مسلم، سنن أبي داود، جامع الترمذي، سنن النسائي، سنن ابن ماجه، موطأ مالك، مسند الإمام أحمد، وسنن الدارمي. أزيلت الأربعون النووية والأحاديث القدسية من هذه الشاشة واستُبدلت بمسند الإمام أحمد وسنن الدارمي.

## البنية

لكل مصدر ملف مستقل باسم `sakina_<book>.db`، ويحتوي على الجداول `collections` و`books` و`chapters` و`hadiths`. التسلسل داخل القارئ هو: المصدر، ثم الكتاب الداخلي، ثم الباب، ثم الحديث. تبقى المقدمات الموجودة في المصدر ضمن قاعدة الكتاب، وتُقرأ من طبقة Android الأصلية عند توفر القاعدة محليًا.

## التشغيل داخل Android

تستخدم الواجهة إضافة Capacitor باسم `HadithNative`. تتولى الإضافة تنزيل الملف مع الاستكمال، والتحقق من SHA-256، والتخزين المحلي، وحذف القاعدة، وقراءة الفهرس والأحاديث والبحث. لا تعتمد منظومة الحديث على JSON الخارجي أو IndexedDB أو عامل Web Worker أو مسار API للحديث.

تظهر للمستخدم حالات التنزيل بالعربية فقط: غير محمل، جارٍ التنزيل، جارٍ التجهيز، جاهز، أو تعذر مع إمكانية الاستكمال. لا تعرض الواجهة حجم الملف أو تفاصيل SQLite أو قيمة البصمة.

## سلامة بطاقة المشاركة

بطاقة مشاركة الحديث وخدمة تصديرها مستقلتان عن مصدر البيانات، ولذلك بقيت ملفات `src/components/hadith-share/` و`src/services/hadith-share-native.ts` دون تعديل في هذا النقل.
