# docs/widget-shots — أدلة الويدجت

| ملف | ماذا يحتوي |
|---|---|
| `index.html` | المعرض المرجعي (8 بطاقات) + جدول الألوان + جدول تعارضات المواصفات + جدول «غير مُتحقَّق منه» |
| `build_evidence.py` | مولّد `index.html` — يقرأ `values/` و`values-night/colors.xml` مباشرة |

## القيد الصريح

هذه البيئة **لا تحتوي محاكي أندرويد ولا جهازًا موصولًا**، لذلك لا توجد لقطات شاشة حقيقية.
`index.html` رندر مرجعي مبني من قيم التصميم نفسه ليكون **مرجعًا للمقارنة** عند فحص الجهاز،
وليس دليلًا على السلوك وقت التشغيل. البنود التي تحتاج جهازًا (الوضعان، بعد العشاء،
بلا موقع، 130%، logcat) مُدرجة في §4 مع خطوات الاختبار اليدوي.

أعد التوليد بعد أي تعديل على الألوان:

```bash
python3 docs/widget-shots/build_evidence.py
```
